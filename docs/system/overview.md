# System overview

Planned shape, not yet built.

- **Server**: one always-on PC runs the program and serves every page.
- **Displays**: small computers with portrait touch screens open a page in kiosk mode and only display it.
- **Phones and tablets**: any browser on the network opens the same pages.
- **Offline**: no CDN and no web fonts; everything is served from the server.
- **Updates**: the server updates itself on a schedule; displays pick up changes by reloading.
- **Docs**: this site is built from `docs/` and served by the server.

Details for installation, display setup, updates and ports are added here as each part is built.
