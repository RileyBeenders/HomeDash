# Skills and commands

Skills live in `.claude/skills/`; each has a matching slash command in `.claude/commands/`.

## Design flow

| Command | Use it to |
| --- | --- |
| `/design-flow` | Run the whole sequence below, guided |
| `/grill-me` | Stress-test a plan before building |
| `/design-brief` | Write a brief for a feature or page |
| `/information-architecture` | Define navigation, structure and flows |
| `/design-tokens` | Generate or extend tokens |
| `/brief-to-tasks` | Split a brief into buildable tasks |
| `/design-review` | Critique a built screen against the brief |

Artifacts are saved in `.design/<feature>/`.

## Building and polishing UI

| Command | Use it to |
| --- | --- |
| `/design-language` | Load this project's rules before touching UI |
| `/frontend-design` | Build distinctive interfaces |
| `/redesign-existing-projects` | Upgrade something that exists |
| `/prototype` | Compare several different versions side by side |
| `/pick-ui-library` | Choose a library for a task |
| `/mobile-native` | Make a page feel native on phones and kiosks |
| `/apple-design`, `/emil-design-eng` | Craft philosophy references |

## Motion

| Command | Use it to |
| --- | --- |
| `/animate` | Build an animation |
| `/review-animations` | Review motion code |
| `/find-animation-opportunities` | Find what should animate |
| `/improve-animations` | Audit and plan motion fixes |
| `/animation-vocabulary` | Name an effect you can't describe |

## Git and releases

| Command | Use it to |
| --- | --- |
| `/write-commit` | Draft a commit message (output in chat) |
| `/write-merge` | Draft a PR and merge text |
| `/update-version-history` | Add merged PRs to `VERSION_HISTORY.md` |
| `/create-html-PR` | Make a plain-language update page from merged PRs |
