# HomeDash

Home dashboard hosted on one PC and shown on small portrait touch displays and any browser on the network.

Status: design language and tooling only; the app is not built yet.

- Design language: [`docs/design/`](docs/design/index.md), tokens in [`docs/assets/tokens.css`](docs/assets/tokens.css), live demo in [`docs/assets/style-guide.html`](docs/assets/style-guide.html)
- Claude skills and commands: [`.claude/`](docs/workflow/skills-and-commands.md)
- Version control: [`docs/workflow/version-control.md`](docs/workflow/version-control.md)
- Docs site: `pip install mkdocs-material`, then `mkdocs serve -f mkdocs/mkdocs.yml`
